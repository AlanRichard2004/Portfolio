# Alan Richard M | Portfolio

Static site: `index.html`, `style.css`, `script.js` and `img/alan.jpg`. No build step.

## Before you publish
1. Open `script.js` and fill in the `LINKS` block at the top (LinkedIn, GitHub, resume file, project repos). Empty entries stay hidden.
2. To offer a resume download, put the PDF next to `index.html` and set `resume` to its file name.
3. Replace `img/alan.jpg` if you want a different photo (keep the 4:5 shape).

## Publish for free
- **Vercel or Netlify:** drag this folder onto the dashboard.
- **GitHub Pages:** push the folder to a repository, then Settings > Pages > deploy from the main branch.

## Tips
- Visitors can press Ctrl+P (or use "Save as PDF" on the page) for a clean printable version.
- Animations switch off automatically for people who prefer reduced motion.
